## Local Development

- Install dependencies from the repository root with `pnpm install`.
- Run the frontend and local Express/SQLite API together with `pnpm dev`.
- Run workspace typechecks with `pnpm typecheck`.
- Build the frontend with `pnpm build`.
- The database and uploads live under ignored `data/` and `uploads/` directories.
- The local admin password is generated in `data/admin-password.txt` on first
  start.
